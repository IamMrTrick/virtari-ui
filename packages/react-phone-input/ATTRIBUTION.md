# Attribution

This package derives country metadata (dial codes, native names) at build time
from [`world-countries`](https://github.com/mledoze/countries) by Mohammed Le Doze.

The `world-countries` dataset is licensed under the Open Data Commons Open
Database License (ODbL). Any database that contains a substantial portion of
the data must preserve the attribution.

> Contains information from [world-countries](https://github.com/mledoze/countries),
> which is made available under the ODC Attribution License.

Translated country names are sourced from
[`i18n-iso-countries`](https://github.com/michaelwittig/node-i18n-iso-countries)
(MIT) at build time.

Phone-number parsing / validation / formatting is powered by
[`libphonenumber-js`](https://gitlab.com/catamphetamine/libphonenumber-js) (MIT),
which ships as a runtime dependency.

See the upstream repositories for full license text.
