# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities through GitHub's private vulnerability
reporting flow on the repository's **Security** tab. Do not open a public issue
or include credentials, access tokens, customer data, or exploit details in a
public discussion.

Include the affected component or CLI version, reproduction steps, impact, and
any suggested mitigation. Virtari will acknowledge the report, investigate it,
and coordinate disclosure after a fix is available.

## Supported versions

Security fixes target the latest published Virtari CLI and the current `main`
branch. Source-installed components should be compared with the latest registry
version using `virtari diff` before applying an update.
